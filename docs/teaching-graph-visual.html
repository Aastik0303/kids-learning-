Teaching Graph — nodes & edges

The classroom expressed as five graphs, 60 nodes and 77 edges. Colour carries the owner; shape carries the node type.

CG

Concept Graph — 25 nodes

One concept, from first exposure to MASTERED or PARK. Everything above CG.15 COMMIT is deterministic; every agent node sits below it, so an agent failure can never cost the child progress.

CG.13 evaluate is the truth node. Its only inbound edge is CG.12 and its only outbound edge is CG.14. It must not reach app/agents/ or app/ai/ through any import path — enforced by AST walk in tests/contract/test_truth_node_isolation.py, not by review.

CG.18 → CG.25 is a hard cap. At four attempts the concept parks, whatever the agent or the policy would prefer. The concept is not marked failed — it returns tomorrow, and everything downstream of it stays locked until it is genuinely learned.

Why CG.18 instant_ack is a node and not a flag. The repair path CG.19 → CG.20 → CG.21 takes about 1.4 s. A three-year-old disengages in that silence. CG.18 emits a deterministic filler at 0 ms, before the agent is invoked; the agent's line arrives while the filler is still being spoken and cuts it mid-sentence — which is what a real teacher does. Without this node the agent architecture is not shippable to this age group.

SG

Session Graph — 15 nodes

One app open: authenticate, load the learner, plan the day, open the class, run each plan item through the concept graph, close.

SG.06 → SG.11 is the freeze rule. A plan is generated once per (child_id, plan_date) and read thereafter. Refresh, re-login and back-navigation all take that edge. Without it the planner agent produces a slightly different plan every time and the child never builds a routine.

SG.08 → SG.07 is the only retry in the system. One retry, then deterministic. Three retries on an eight-second agent is a twenty-four-second wait for a four-year-old.

TA

Teacher Agent — 8 nodes

A bounded ReAct loop: at most four steps, six read-only tools, a 2.5 s deadline, one schema retry, and a guaranteed abort edge to the deterministic branch engine.

TA.01 build_context is the single choke point. Every LLM call in the system passes through it. It excludes correct_answer and accepted_answers — so the model cannot reveal an answer even if a child asks directly, which is the first thing a four-year-old asks a guide.

The model is told what was decided and asked to say it. It is never asked what to do. That inversion is what makes "the LLM is never a source of truth" structurally true rather than aspirational.

Five tests the graph form makes possible

This is the real argument for writing the system as an explicit node/edge table rather than a pile of service calls: these checks are trivial against a graph and near-impossible against call sites.
