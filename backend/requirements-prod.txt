# What the deployed API installs. `requirements.txt` is the developer's list -
# it carries pytest, httpx-as-a-test-client and sentence-transformers, and that
# last one drags torch (~2GB) in with it.
#
# `app/playground/rag.py` imports sentence-transformers *inside* the function
# that builds the embedding index and falls back to keyword search when the
# import or the model load fails, so leaving it out here is a supported way to
# run: retrieval is keyword-only, the AI Teacher still teaches, and the image
# fits a small instance. Add `sentence-transformers>=3.0,<6` back to this file
# on an instance with 2GB of RAM to spare and the index builds itself at boot.

# Signed parent session tokens, and the Google ID tokens verified at sign-in.
#
# `[crypto]` is not optional here even though the app's own tokens are HS256:
# a Google ID token is signed RS256, and without `cryptography` PyJWT cannot
# verify one at all. Left off, the image builds, boots, serves every other
# route, and refuses every single Google sign-in with "we could not confirm
# that" - which reads like a misconfigured client id rather than a missing
# wheel. See `app/services/google_auth_service.py`.
PyJWT[crypto]>=2.8,<3
